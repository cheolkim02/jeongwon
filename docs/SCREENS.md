# 정원 — 화면 시안 명세 (Phase 1)

신청서에 붙일 화면 시안을 만든다. 기능은 없고, 예시 데이터로 "앱을 켰을 때 어떻게 보이는지"를 보여 준다. 이 화면 코드는 Phase 2에서 실제 계산 결과를 받아 그대로 쓴다.

## 1. 캡처 기준
- 세로 390×844, 배율 3으로 저장한다.
- 화면들을 모은 한 장(/showcase, 1920×1080)도 만든다. 신청서에는 이 한 장과 개별 화면 2~3장을 넣는다.
- 날짜는 2026년 11월 26일 아침으로 고정한다.

## 2. 디자인 방향
키워드: 따뜻한 미니어처, 살아 있는 정원, 곁에 있는 비서. 숫자로 가득한 대시보드처럼 보이면 실패다. 첫눈에 들어오는 것은 그림(우리 집, 정원)이고, 숫자는 한두 개만 크게 쓴다.

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| 배경 | #F6F2EA | 따뜻한 종이색 |
| 카드 | #FFFFFF, 모서리 20px, 아주 옅은 그림자 | |
| 글자 | #23261F, 보조 #6B6F66 | |
| 정원(주색) | #2F7D55, 새잎 #8CC63F | 버튼, 진행 바, 식물 |
| 점검 빛 | #FFB547(번지는 빛) | 미니어처의 살펴볼 곳 |
| 전기·수도·난방 | #E8B931 · #3E8ED0 · #E07A4F | 작은 아이콘과 칩에만 |

- 글꼴: Pretendard. 큰 숫자는 굵기 700, 자리 맞춤 숫자(tabular-nums).
- 좌우 여백 20px, 요소 사이는 넉넉하게.
- 그림체: 아이소메트릭(30°), 윤곽선 없이 면마다 3톤 음영(윗면 밝게, 왼쪽 면 중간, 오른쪽 면 어둡게). 미니어처·정원·단지 그림이 모두 같은 그림체.
- 생명의 기운: 식물 주위에 작은 빛 입자 몇 개. 점검 빛은 숨 쉬듯 천천히 밝아졌다 어두워진다(약 2.5초). 과하지 않게. 스크린샷에는 가장 밝은 순간이 찍히게 한다.
- 하지 않을 것: 빨간 경고, 순위·등수, 계기판 바늘, 여러 줄 꺾은선 차트, 실제 브랜드 로고, 이모지 남발.

## 3. 공통 요소
- 하단 탭바 4개: 우리 집 · 검진 · 정원 · 단지(아이콘 + 글자)
- 화면 맨 아래 작은 회색 글씨: "예시 데이터 · 정원 프로토타입"
- 휴대폰 상태 표시줄은 그리지 않는다.

## 4. 화면

### ① 우리 집(홈) — `/`
목적: 앱을 켜자마자 "우리 집 어디를 봐야 하는지"와 "정원이 자라고 있다"가 한눈에 들어온다.

1. 작은 워드마크 "정원", 오른쪽에 알림 아이콘(점 하나)
2. 인사 "좋은 아침이에요" / 큰 글씨 "우리 집에 살펴볼 곳이 1곳 있어요"
3. 우리 집 미니어처(폭 가득, 화면 높이의 약 45%)
   - 84㎡ 판상형 3베이 평면: 앞쪽 발코니 / 작은방1 · 거실 · 안방 / 뒤쪽 작은방2 · 주방 · 공용 욕실 · 현관 · 안방 욕실
   - 벽은 낮게 잘라 안이 보이는 모형집처럼. 가구는 단순한 덩어리(소파, 침대, 식탁, 변기·세면대, 냉장고) 정도만
   - 공용 욕실이 점검 빛으로 빛나고, 말풍선 "새벽에도 물이 흘러요"가 붙는다. 누르면 ②
   - 거실 앞 발코니에 화분 하나. 지금 단계는 '묘목'
   - 방 배치는 데이터(방 id, 위치, 크기)로 정의하고 투영 함수로 그린다. 점검 위치는 방 id로 지정한다.
4. 이번 달 카드: "11월 예상 요금" 큰 숫자 / 전기 · 수도 · 난방 칩(각 금액) / "전기는 작년 11월보다 4.1% 덜 쓰고 있어요"
5. 정원 한 줄 카드: 묘목 아이콘, "목표 3% · 지금 4.1% 아끼는 중", 목표 위치가 표시된 진행 바. 누르면 ③

완료 기준: 스크롤 없이 한 화면에 다 보인다. 빛나는 욕실이 가장 먼저 눈에 들어온다.

### ② 검진 — `/checkup`, `/checkup/leak`
`/checkup`(목록): 맨 위에 "살펴볼 곳 1" 카드(욕실 · 새벽에도 물이 흘러요). 그 아래 괜찮은 항목 2개와 초록 체크: "대기 전력 · 비슷한 집들과 비슷해요", "난방 · 작년 이맘때와 비슷해요".

`/checkup/leak`(상세, 스크린샷 대상):
1. 뒤로 가기, 제목 "우리 집 검진"
2. 미니어처의 욕실 부분을 확대한 그림(빛나는 상태)
3. 제목 "새벽 3시에도 물이 흐르고 있어요"
4. 설명 "물을 쓰지 않는 새벽에도 6일째 시간당 약 8L가 흐르고 있어요. 가장 흔한 원인은 변기 누수예요."
5. 근거 그래프: 최근 14일의 '새벽 최소 유량'(L/시간) 막대. 앞 8일은 낮고 뒤 6일은 높다. 평소 수준은 점선. 막대는 수도 파랑이고, 최근 6일만 점검 빛 색.
6. 손실 카드: "이대로면 이번 달 약 1만 원이 더 나와요" / 작은 글씨 "서울에서는 2020년부터 변기 누수로 더 나온 수도요금을 감면해 주지 않아요"
7. 해 볼 일 2가지
   - "변기 물탱크에 식용색소를 몇 방울 넣고 10분 기다려 보세요. 변기 물 색이 바뀌면 새는 거예요."
   - "집 안 수도를 모두 잠그고, 수도 계량기의 별 모양 표시가 돌아가는지 보세요."
8. 버튼: 주 버튼 "my HILLS로 A/S 접수하기" / 보조 버튼 "확인했어요"

완료 기준: 유형, 근거 그래프, 월 손실액, 해 볼 일이 모두 있다(FR-A6). 빨간색이 없다.

### ③ 정원 — `/garden`
1. 제목 "우리 집 정원"
2. 큰 그림: 발코니 화분의 묘목과 주위의 빛 입자. 아래에 단계 표시 씨앗 · 새싹 · 묘목 · 나무(지금 단계 강조)
3. 목표 카드: "11월 목표 · 작년 11월보다 3% 아끼기" / "약 9kWh · 날씨 차이는 빼고 계산해요" / 오른쪽 작은 링크 "목표 바꾸기"(⑥)
4. 진행: "11월 26일까지 4.1% 아꼈어요", 진행 바(3% 위치에 목표 표시), "이대로면 월말에 나무가 돼요"
5. 내가 키운 나무: 9월 · 10월 나무 두 그루와 11월 자리의 묘목. 목표를 못 채운 달은 빈칸이나 시든 그림 없이 그냥 넘어간다.
6. 버튼 "10월 정원 카드 보기" → ④

완료 기준: 시들거나 줄어드는 표현이 없다(FR-B4). 순위가 없다.

### ④ 정원 카드 — `/garden/card`
공유용 세로 카드(9:16)를 화면 가운데에 크게 보여 준다.
- 카드 안: "10월의 정원" / 미니어처의 발코니에 다 자란 나무 / "목표 3% → 5.3% 달성" / "우리 단지 숲에 소나무 1그루를 보탰어요" / 작은 글씨 "약 16kWh = 30년생 소나무 1그루가 1년 동안 흡수하는 양" / "#정원 #에너지갓생"
- 카드 아래: 토글 "아낀 금액도 보여 주기"(꺼짐), 버튼 "이미지 저장" · "인스타그램 스토리"

완료 기준: 카드 안에 동·호수, 날짜·시간대, 단지 이름이 없다(FR-B6).

### ⑤ 단지 정원 — `/complex`
1. 제목 "우리 단지 정원"
2. 큰 그림: 아이소메트릭 아파트 동 4~5개 사이로 작은 소나무 숲. 숲의 크기는 진행률에 맞춘다.
3. 큰 문장 "이번 겨울, 소나무 1,700그루를 키워요" / "지금 420그루 · 25%"와 진행 바
4. 작은 숫자 2개: "함께하는 집 640세대", "이번 주 새로 자란 소나무 96그루"
5. 설명 "집집마다 아낀 전기를 소나무로 바꿔 모아요. 목표를 채우면 단지에 진짜 나무를 심어요."
6. 버튼 "우리 단지 정원 공유하기"

완료 기준: 동별·세대별 비교나 순위가 없다. 모든 숫자는 단지 전체 합계다.

### ⑥ 목표 고르기(선택, 시간이 남으면) — `/garden/goal`
아래에서 올라오는 시트. 제목 "이번 달 목표를 골라 주세요", 설명 "작년 같은 달과 비교하고, 날씨 차이는 빼고 계산해요."
- 1% · 가볍게
- 3% · 추천, 에너지캐시백 기준(기본 선택)
- 5% · 도전, 탄소중립포인트 기준
- 버튼 "자동으로 정해 줘" / "이걸로 할게요"

### 모아 보기 — `/showcase`(1920×1080)
왼쪽 위에 "정원"과 한 줄 소개 "새는 돈은 찾아 주고, 아낀 만큼은 정원으로 키워 주는 AI 에너지 비서". 그 아래 휴대폰 4대와 각각의 한 줄 설명:
- ① 우리 집 — "살펴볼 곳이 빛나는 우리 집"
- ② 검진 상세 — "새는 곳과 새는 돈을 알려 줘요"
- ③ 정원 — "내 목표로 자라는 정원"
- ④ 정원 카드 — "자랑하고 싶은 정원 카드"

배경은 디자인 배경색. 휴대폰 틀은 단순한 둥근 사각형으로, 실제 기종 모양을 흉내 내지 않는다.

## 5. 예시 데이터
입력값만 web/src/mock에 두고, 화면 숫자는 calc 함수가 만든다. 아래 표시값은 테스트로 확인한다.

| 항목 | 입력 | 계산 | 화면 표시 |
| --- | --- | --- | --- |
| 이번 달 전기 | 작년 11월 기준선 312kWh(날씨 보정 후), 11월 30일 중 26일 지남, 26일까지 사용 259.3kWh | 기준선 26일분 = 312×26/30 = 270.4, 절약 = 11.1kWh, 절약률 = 11.1/270.4 | "4.1%" |
| 목표 | 3% | 312×0.03 = 9.36kWh | "약 9kWh" |
| 정원 단계 | 절약 ÷ 목표 = 11.1/9.36 = 1.19 | 0.3 미만 씨앗, 0.7 미만 새싹, 그 이상 묘목. 나무는 월말에 달성이 확정될 때만 | "묘목", "이대로면 월말에 나무가 돼요" |
| 누수 | 최근 14일 새벽 최소 유량(L/시간): 0.6, 0.4, 0.8, 0.5, 0.7, 0.3, 0.6, 0.5, 7.8, 8.2, 8.1, 7.9, 8.0, 8.3 / 최소 유량 시각 3시 | 임계치 2L/시간 초과 연속 일수 = 6, 누수 유량 = 최근 6일 중앙값 8.05, 월 누수량 = 8.05×24×30/1000 = 5.80㎥, 손실액 = 5.80 × 수도 단가 | "6일째", "약 8L", "약 1만 원" |
| 10월 카드 | 작년 10월 기준선 300kWh, 10월 사용 284.2kWh | 절약 15.8kWh, 절약률 5.3%, 소나무 = 15.8 ÷ 15.82 | "5.3% 달성", "소나무 1그루" |
| 단지 | 1,024세대 중 640세대 참여, 겨울(11~2월) 목표 1,700그루, 지금 420그루, 이번 주 96그루 | 진행률 = 420/1,700 | "25%" |
| 11월 예상 요금 | 26일까지 수도 10.4㎥, 난방 420Mcal | 월말 예상 = 26일까지 사용량 × 30/26, 전기는 누진 구간 계산, 단가는 constants | 계산값 그대로 |

표시 규칙: 금액은 천 원 단위로 반올림해 "약 1만 원", "약 11만 2천 원"처럼. 퍼센트는 소수 첫째 자리(단지 진행률만 정수). kWh·L는 정수로 "약 9kWh". 소나무는 1그루 이상이면 정수, 미만이면 소수 첫째 자리.

constants(값과 출처를 주석으로):
- 전기 주택용 누진(2026, 기타계절): 1단계 200kWh 이하 120원/kWh, 2단계 201~400kWh 214.6원/kWh, 3단계 단가·기본요금은 TODO(Phase 1은 전력량요금만)
- 수도 단가(상수도+하수도+물이용부담금): 임시 1,700원/㎥, TODO 공식 요금표 확인
- 지역난방 단가: 임시값, TODO
- 소나무 환산: 30년생 소나무 연간 CO2 흡수 6.6kg(국립산림과학원) ÷ 전력 배출계수 0.4173kgCO2/kWh = 15.82kWh당 1그루·1년
- 누수 임계치: 새벽 최소 유량 2L/시간(임시)
