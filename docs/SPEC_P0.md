# 정원 — 프로토타입 기능 명세 (Phase 2)

전체 요구사항은 SRS(IEEE 830 양식, claude.ai 문서)에 있고, 이 파일은 본선 전에 실제 계산을 붙일 범위(P0)만 뽑은 것이다. 요구사항 ID는 SRS와 같다. 화면 시안(Phase 1)은 docs/SCREENS.md가 기준이며, P1 기능(나무 환산, 단지 정원)도 그림으로는 보여 줄 수 있다.

## 한 문장
새는 돈은 찾아 주고, 아낀 만큼은 정원으로 키워 주는 AI 에너지 비서.

- 테마 A, 새는 돈 찾기(우리 집 검진): 비슷한 이웃·작년의 우리 집과 비교한 이상치로 누수·노후 가전·단열 문제를 찾는다.
- 테마 B, 아낀 만큼 자라는 정원: 이웃 순위가 아니라 내 목표(작년 같은 달 대비, 기온 보정)로 정원이 자라고, 카드로 공유한다.
- 무대: 우리 집 미니어처(세대 평면 타입의 2.5D 그림). 홈 화면이자 두 테마의 결과가 나타나는 곳.

## 데모 시나리오 (심사위원이 보는 3장면)
1. 아침 알림 → 미니어처의 욕실이 따뜻하게 빛남. "새벽 3시에도 물이 흐르고 있어요. 이대로면 이번 달 약 ○원이 더 나와요." → 상세(근거 그래프, 추정 손실액, 해 볼 일) → A/S 접수(모의).
2. 사용량이 작년 같은 달보다 줄면 발코니의 새싹이 나무로 자란다(진행률 표시).
3. 월말: 미니어처와 정원이 카드 한 장이 되어 이미지로 저장·공유된다.

## P0 요구사항과 수용 기준
| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-A1 | 비교군 배정: 평형·층 구간·세대 위치·가구원 수·난방 방식이 같은 세대를 묶고, 10세대 미만이면 기준을 풀어 합친다(합성 데이터의 세대 속성 사용) | 모든 세대가 10세대 이상 비교군에 속하고 규칙이 설정 파일에 있다 |
| FR-A2 | 기준선: 세대별 '작년 같은 달(기온 보정)'과 '비교군 시간대별 중앙값'. 작년 데이터가 없으면 비교군만 | 표본 3세대가 수계산과 일치 |
| FR-A3 | 누수 의심: 새벽 최소 유량이 N일 연속 임계치 초과 | 합성 누수 주입 사례를 모두 잡고, 미주입 세대의 오탐률을 보고 |
| FR-A4 | 상시 전력 증가: 새벽 상시 전력이 비교군 상위 구간이거나 작년 같은 달보다 X% 이상 증가 | 합성 사례 탐지, 알림에 우리 집과 비교군의 W 표시 |
| FR-A6 | 알림 내용: 유형, 근거 수치와 그래프, 추정 월 손실액(원), 해 볼 일 | 모든 알림에 네 항목 |
| FR-A9 | 비교 표시 원칙: 순위·등수 없음, 비교군보다 많으면 원인 후보와 행동을 함께 | 어떤 화면에도 순위·등수가 없다 |
| FR-A10 | 미니어처 점검 표시: 누수 → 욕실·주방, 상시 전력 → 등록 가전 후보 위치(없으면 거실), 단열 → 외벽 창. 누르면 상세, '확인했어요'로 닫기 | 합성 사례가 정해진 위치에 표시되고, 닫은 표시는 다시 나오지 않는다 |
| FR-B1 | 자동 목표: 기준선 대비 3%(1%·3%·5% 선택). 3%는 에너지캐시백 기본 기준, 5%는 탄소중립포인트 기준에서 가져옴 | 목표가 원과 kWh로 표시 |
| FR-B3 | 진행률: 매일 누적 절감량과 월말 예상 달성 여부 | 표본 세대가 수계산과 일치 |
| FR-B4 | 정원 성장: 씨앗→새싹→묘목→나무, 달성한 달마다 나무 1그루가 남는다. 시들거나 줄어드는 표현 금지 | 달성·미달 두 경우 화면이 규칙대로 |
| FR-B6 | 공유 카드: 미니어처·정원 그림, 달성률, (선택) 절감액. 동·호수·시간대 정보 없음 | 저장 이미지에 금지 항목이 없다 |
| FR-C1 | 온보딩: 세대 선택(데모), 가구원 수·난방 방식 확인, 목표 선택 | 3단계 안에 끝난다 |
| FR-C2 | 미니어처 홈: 점검 하이라이트, 발코니 정원, 오늘·이번 달 요금을 한 화면에 | 스크롤 없이 한 화면 |
| FR-C3 | 요금 환산: 전기(주택용 누진), 수도, 난방을 원으로. 요금표는 적용 기간과 함께 설정 파일에 | 표본 세 달의 전기요금이 수계산과 일치 |

알림 설명 문장(FR-A6의 '해 볼 일' 문구)은 LLM으로 만들어도 되지만, 입력은 탐지 결과 JSON뿐이고 숫자는 JSON 값을 그대로 쓴다. 키가 없으면 템플릿 문장으로 대체한다.

## P1 (본선용)
FR-A5 단열·창호 의심, FR-A7 A/S 모의 접수 화면, FR-A8 오탐 피드백 이유, FR-B2 직접 목표, FR-B5 나무 환산 표시, FR-B7 단지 정원, FR-C4 자연어 질문(NL2SQL), FR-C5 알림 빈도, FR-C6 가전 등록.

## 데이터와 상수
- 검침: 합성 세대 데이터. pipeline이 seed를 고정해 생성한다. 한 단지 300세대 × 13개월 이상, 시간별 전력·수도·난방. 세대 속성(평형·층·위치·가구원 수·난방 방식)을 포함하고, 이상치(누수, 상시 전력 증가)를 정답 목록과 함께 주입한다. 사용량 수준과 계절 패턴은 공개 통계에 맞추고 출처를 README에 적는다.
- 기온: 기상청 종관기상관측(ASOS) 서울 시간 자료(기상자료개방포털에서 CSV로 받기). 어려우면 합성.
- 실데이터 대안: 본선에서 현대건설이 데이터를 주지 않고 실측이 꼭 필요할 때만, 서울시 '홈에너지 시간별 사용 데이터셋'(공공누리 4유형: 출처표시·상업적 이용금지·변경금지)을 라이선스 확인 후 검토한다. 원본은 커밋하지 않는다.
- 전기요금(2026 기타계절 주택용): 1단계 200kWh 이하 120원/kWh, 2단계 201~400kWh 214.6원/kWh. 3단계 단가와 기본요금, 수도·지역난방 단가는 공식 요금표에서 확인해 설정 파일에 출처와 함께 적는다(TODO)
- 나무 환산: 30년생 소나무 연간 CO2 흡수 6.6kg(국립산림과학원 2012 표준) ÷ 전력배출계수 0.4173 tCO2eq/MWh(2023년, 2025.12 공표) ≈ 15.8kWh당 1그루·1년
